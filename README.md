# 关卡设计工作台

在 2D 平面上设计多层关卡，可自由拖动编辑、编辑墙体与门窗，并切换到 3D 预览查看楼层之间的空间关系。纯前端、零依赖、无需构建。

## 在线使用

直接用浏览器打开即可（GitHub Pages 托管）：

- `index.html` —— 正式版（分文件）
- `level-studio-standalone.html` —— 单文件版（CSS/JS 全内联，可下载后离线打开，或发到 iPad / 手机上用）

## 功能

**编辑模式**
- `⊞ 网格` / `✥ 自由` 两种拖动模式（快捷键 `G`）。自由模式下画图形、拖物体、缩放顶点都不受格子约束；网格模式可选吸附步长 1 / 0.5 / 0.25。
- 无论哪种模式，按住 `Shift` 可临时反转（网格里微调、自由时对齐都靠它）。

**楼层**
- 默认 5 层，上限 999 层。「空间设置 → 楼层数量」可一次增减到任意层数。
- 每层高度可单独改；`默认层高` 会整体重排。
- 楼层标题的 `⧉` 可整层复制（体块、墙、门窗一起复制到新楼层）。
- 顶部楼层选择器带 `‹ ›` 快速翻层。

**工具**（左侧工具栏）

| 快捷键 | 工具 | 说明 |
| --- | --- | --- |
| `V` | 选择 / 移动 | 拖动移动，Alt 拖动复制 |
| `R` | 方形 | |
| `C` | 圆形 | |
| `A` | 箭头 | |
| `S` | 楼梯 | 台阶数、上升楼层数、上楼方向 |
| `W` | 墙体 | 折线墙，逐点点击，点回起点闭合，双击 / Enter 结束 |
| `D` | 门 | 点墙体开门洞，可沿墙拖动 |
| `N` | 窗 | 点墙体开窗洞，可调窗台高 |
| `E` | 编辑顶点 | 拖动顶点改轮廓，点边上的 `+` 加点 |
| `H` | 平移画布 | |

**墙体与门窗**
- 墙体属性：厚度、高度、是否闭合。新建墙体自动使用**所在楼层的配色**，改所属楼层 / 跨层复制时会自动跟随。
- 门：位置（沿墙 0–1）、门宽、门高、开向、关闭 / 开启 90°、颜色。
- 窗：位置、窗宽、窗高、**窗台高**、玻璃颜色。窗台以下留窗台墙、以上留过梁。
- 门和窗都是真正挖穿墙体的开口，不是贴图。

**3D 预览**
- 拖动旋转视角，可单独调墙体 / 门 / 窗 / 楼板的不透明度。
- 楼梯只保留踏面与立面，门可开合，窗是半透明玻璃。

**其他**
- 撤销 / 重做（`Ctrl+Z` / `Ctrl+Shift+Z`）
- 导出 / 导入关卡 JSON（`format: level-studio`，version 3，兼容导入 v2）
- 图层面板：显隐、锁定、重命名、排序、复制、删除

**触屏**
- 单指绘制 / 拖动，双指缩放与平移，3D 下单指旋转。

## 本地开发

```bash
# 任意静态服务器即可，例如
python3 -m http.server 8321
# 然后打开 http://localhost:8321
```

改完源码后重新生成单文件版：

```bash
node build-standalone.js
```

## 文件结构

```
index.html          页面结构
style.css           样式
geometry.js         几何计算（投影、楼梯、墙体开口切分）
app.js              编辑器主逻辑
build-standalone.js 打包成单文件 HTML
favicon.svg         图标
```
